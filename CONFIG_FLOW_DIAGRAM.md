```
                                  │

│                                                                         │
│ # 智能探測流程：                                                         │

│                                                                         │
│ 內部調用：                                                               │
│ ├─ self._calculate_optimal_ladder_count(actual_available)              │
│ │  └─ 根據實際可用餘額計算最佳階梯檔數 (1-10檔)                        │
│ └─ self.ladder_strategy.generate_ladder_rates()                        │
│    └─ SimpleLadderStrategy 生成動態階梯利率                             │
```

```
│                    Lines 62-118 (simple_ladder_strategy.py)                │

                                       │
  ┌────────────────────────────────────┴────────────────────────────────────┐
  │                                                                         │
  ▼                                                                         ▼
┌─── 📊 獲取市場數據 ─────────────────────────────────────────────────────┐
│ market_summary = self.market_data.get_market_summary(currency)           │
│                                                                          │
│ 內部調用 market_data.py：                                                │
│ ├─ get_recent_funding_rates('UST', limit=10)                            │
│ │  └─ 獲取最近10筆UST成交數據                                            │
│ │  └─ 計算平均日利率                                                     │
│ └─ get_funding_book_rates('UST', depth=25)                              │
│    └─ 獲取資金簿前25檔                                                   │
│    └─ 分析競爭對手利率分佈                                               │
└──────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─── 🧮 智能利率計算 ─────────────────────────────────────────────────────┐
│ # 市場數據示例：                                                         │
│ recent_avg = 0.000221    # 最近成交平均 (約8.06%年化)                    │
│ bid_avg = 0.000000      # 競爭對手平均 (無競爭對手)                      │
│ bid_count = 0           # 競爭檔數                                       │
│                                                                          │
│ # 基準利率計算：                                                         │
│ if bid_avg > 0 and recent_avg > 0:                                      │
│     base_rate = bid_avg * 0.6 + recent_avg * 0.4                       │
│ else:                                                                    │
│     base_rate = recent_avg  # = 0.000221                               │
│                                                                          │
│ # 競爭緩衝：                                                             │
│ competitive_rate = base_rate * 1.05  # +5% = 0.000232                  │
└──────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─── 🎯 策略選擇 ─────────────────────────────────────────────────────────┐
│ if bid_count >= 15:                                                     │
│     strategy = 'conservative'  # 競爭激烈                               │
│     ladder_top = competitive_rate * 1.05                               │
│ elif bid_count >= 8:                                                   │
│     strategy = 'balanced'      # 中等競爭                               │  
│     ladder_top = competitive_rate * 1.10                               │
│ else:                                                                   │
│     strategy = 'aggressive'    # 競爭較少 ←← 當前情況                    │
│     ladder_top = competitive_rate * 1.15  # = 0.000267                 │
│                                                                          │
│ 結果：8.465% - 9.743% 年化利率範圍                                       │
└──────────────────────────────────────────────────────────────────────────┘
                                  │
                                  ▼
┌─── 🪜 階梯分佈生成 ─────────────────────────────────────────────────────┐
│ levels = 3  # 動態計算的檔數                                             │
│ rate_increment = (ladder_top - ladder_base) / (levels - 1)             │
│                                                                          │
│ 生成3檔階梯：                                                            │
│ Level 1: 0.000232 (8.465% 年化) 權重: 33.3%                            │
│ Level 2: 0.000250 (9.104% 年化) 權重: 33.3%                            │  
│ Level 3: 0.000267 (9.743% 年化) 權重: 33.3%                            │
│                                                                          │
│ 返回給 main.py 用於訂單生成                                              │
└──────────────────────────────────────────────────────────────────────────┘
```

## 🔍 關鍵數據流

```
市場數據 → 階梯策略 → 訂單生成 → API提交 → 結果統計
    ↓         ↓         ↓         ↓         ↓
 實時利率   3-10檔    166.50×3   0.024%   Telegram
 競爭分析   權重分配   UST訂單   日利率    通知報告
 緩存5分鐘  動態調整   2天期限   成功率    數據存儲
```

## 🎯 核心創新優勢

1. **🔍 智能探測**: 500 USD 固定測試探測實際可用資金
2. **💰 精準分配**: 基於實際可用金額而非總餘額進行分配
3. **🔄 動態調整**: 訂單失敗時重新分配剩餘資金
4. **🏦 錢包管理**: 自動檢查並轉移資金到正確錢包
5. **📊 多幣種支持**: 支援 USD、UST 等多種放貸幣種
6. **⚡ 競爭優勢**: 5%市場緩衝確保訂單競爭力
7. **🛡️ 風險控制**: 分散到多檔降低單一風險
8. **📱 智能通知**: 詳細的運行報告和收益統計

## 🚀 技術突破

### 解決的核心問題：
- ❌ **舊版問題**: 使用錢包總餘額40,599 ÷ 10 = 4,059 USD每筆
- ✅ **新版解決**: 智能探測實際可用5,000 ÷ 10 = 500 USD每筆
